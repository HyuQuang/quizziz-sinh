🧠 Bảng Tóm Tắt Công Thức Vàng Di Truyền Phân Tử

• Chiều dài gen: L = (N / 2) × 3.4 Å = (N / 2) × 0.34 nm

• Số nucleotide: N = 2A + 2G = 2T + 2C ; %A + %G = 50%

• Số liên kết hydro: H = 2A + 3G = N + G = N + C

• Số chu kỳ xoắn: C = N / 20 = L / 34 Å

• Khối lượng phân tử: M = N × 300 đvC

• Liên kết photphodieste nội mạch: 2 × (N/2 - 1) = N - 2; trong cả phân tử: 2N - 2

• Nhân đôi k lần: Tạo 2^k phân tử ADN con. Môi trường cấp: N_mt = N × (2^k - 1)

• Dịch mã: Số bộ ba trên mRNA = rN / 3. Số amino acid chuỗi polypeptide hoàn chỉnh = (rN / 3) - 2. Số liên kết peptit = (rN / 3) - 3.
